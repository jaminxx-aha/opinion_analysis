## 1 动效卡顿

### 1.1 滑动卡顿

**定义**：在各页面滑动过程中发生卡顿。

**包含场景**：

#### 1.1.1 首页推荐流滑动卡顿
首页推荐商品流上下滑动时卡顿。

#### 1.1.2 商品详情页滑动卡顿
商品详情页上下滑动（看图文详情、评价）时卡顿。

#### 1.1.3 搜索结果列表滑动卡顿
搜索结果商品列表滑动时卡顿。

#### 1.1.4 购物车列表滑动卡顿
购物车商品列表滑动时卡顿。

#### 1.1.5 订单列表滑动卡顿
订单列表（待付款/待发货/已完成等）滑动时卡顿。

#### 1.1.6 评价列表滑动卡顿
商品评价列表上下滑动时卡顿。

#### 1.1.7 个人中心页滑动卡顿
“我的”个人中心页滑动时卡顿。
