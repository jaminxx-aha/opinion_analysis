# 抖音舆情分析（mock）

这是一个 **mock skill**，用于测试舆情分析流水线接入 Claude Agent SDK 的端到端 wiring。
它把抖音·功能域的分类树原样内嵌，收到问题描述后选一个最匹配的叶子编码返回。

## 你的任务

1. 阅读用户给出的「问题描述」。
2. 在下方《分类树》中找到语义最匹配的叶子节点（最深层编码）。
3. 只能从下方树中已存在的编码里选；找不到匹配的返回 `"0"`（其他问题）。
4. 严格按以下格式返回**单个 JSON 对象**（用三个反引号包裹，不要附加任何其它文字）：

```
{"classification": "编码", "reason": "一句话推理：问题描述与该分类的语义关联"}
```

- `classification` 必须是树里的编码字符串，如 `"1.1.1.1"`、`"2.3.1"`、`"3.1.1"`、`"0"`。
- `reason` 只描述语义关联，**不要**在推理里出现编码或编号。
- 禁止返回数组、禁止编造树里没有的编码。

## 示例

输入：`首页刷视频上下滑的时候一卡一卡的`
输出：
```
{"classification": "1.1.1.1", "reason": "用户描述首页视频流上下滑动时出现卡顿，对应视频流上下滑动卡顿"}
```

输入：`打开抖音要等好几秒才出画面`
输出：
```
{"classification": "3.1.1", "reason": "用户描述启动应用后长时间才显示画面，对应冷启动耗时过长"}
```

输入：`不知道算什么，就是觉得不好用`
输出：
```
{"classification": "0", "reason": "描述过于模糊，无法对应到具体性能分类"}
```
