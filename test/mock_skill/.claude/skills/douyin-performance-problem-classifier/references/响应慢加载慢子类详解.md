
# 响应慢/加载慢
## 1 按钮点击响应慢

**定义**：在点击按钮时，响应不及时，有明显的迟钝。

**典型场景**：
- 点击发布按钮没反应，过一会儿才有反应
- 点击评论按钮延迟
- 点击关注按钮慢

**判断要点**：用户描述的是**点击按钮**这个操作本身响应慢。

## 2 手势操作响应慢

**定义**：在进行手势操作（如侧滑、上下滑）时，相应有明显的迟钝，页面状态不跟手。

**典型场景**：
- 侧滑返回响应慢
- 上下滑动页面不跟手
- 双指缩放响应慢

**判断要点**：用户描述的是**手势操作**响应慢，页面状态跟不上手势。

## 3 页面加载慢

**定义**：页面的内容加载很慢，需要较长的时间才能加载出来。

**包括页面类型**：
- 评论列表加载慢
- 消息列表加载慢
- 个人主页加载慢
- 社交列表加载慢
- 搜索内容加载慢
- 购物页面加载慢

**购物页面加载慢进一步细分**：

| 子类 | 包含页面 |
|------|---------|
| **商城加载慢** | 商品列表页、商品详情页、搜索结果页、购物车页面、店铺页面 |
| **团购加载慢** | 团购首页、搜索结果页、店铺页、商品卡片页、评论页、二维码页面、商家联系页 |
| **订单加载慢** | 商城订单页面、团购订单页面（订单页面是通用页面） |
| **付款页加载慢** | 付款页面（通用页面） |
| **我的钱包页面加载慢** | 钱包相关页面 |
| **直播购物加载慢** | 直播间购物相关页面 |

**重要区分**：
- **直播购物加载慢**：页面弹出后，**内容加载**很慢
- **直播卡顿-直播购物卡顿**：页面**弹出**的动效发生了卡顿

## 4 操作无响应

**定义**：操作后页面没有任何反应。

**包含场景**：
- 点击按钮后完全没有反应
- 滑动后页面不动
- 操作后页面卡死

**判断要点**：
- "操作无响应"强调的是**完全没有反应**
- "按钮点击响应慢"强调的是**有反应但很慢**
- "手势操作响应慢"强调的是**有反应但不跟手**

## 5 网络卡顿

**定义**：由于**网络原因**导致了卡顿。

**核心判断标准**：
- 用户反馈中**明确提到**网络原因（如"网速慢"、"网络卡"、"信号差"、"wifi慢"、"5G卡"等） -> 归入"网络卡顿"
- 用户反馈中**未明确提到**网络原因，根据实际现象归类到其他子类

**示例**：
- "网速太慢了，视频加载不出来" -> 网络卡顿
- "点击按钮没反应，等了很久" -> 操作无响应（未明确提到网络）
- "页面加载很慢，一直转圈" -> 页面加载慢（未明确提到网络）
